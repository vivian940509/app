## 🎨 功能特性列表

### ✅ 核心功能（已完成）
- **用戶管理**
  - 登錄/註冊系統
  - 用戶資料管理

- **電影搜尋**
  - TMDB API 整合
  - 關鍵字搜尋
  - 實時搜尋結果

- **電影列表管理**
  - 待追清單（ToWatch）
  - 已看清單（Watched）
  - 新增/編輯/刪除電影

- **電影詳情**
  - 海報顯示（本地 + 遠程）
  - 用戶評分（1-5星）
  - 心得評論
  - TMDB 評分顯示

### ✅ 進階功能（已完成）
- **統計圖表**
  - PieChart：觀看/待追比例
  - BarChart：評分分布
  - LineChart：月度趨勢

- **智能推薦系統**
  - 熱門推薦：TMDB 熱門電影
  - 相似推薦：基於用戶高分電影
  - 過濾邏輯：排除已有電影（已看+待追）

- **社交分享**
  - 分享單部電影
  - 分享觀看統計
  - 支援多平台（Facebook、藍牙等）

- **數據導出**
  - JSON 格式導出
  - CSV 格式導出
  - TXT 格式導出

## 🎯 推薦算法邏輯

```
推薦模式選擇
    │
    ├── 熱門推薦
    │   ├── 從 TMDB 獲取熱門電影
    │   ├── 過濾已有電影（已看+待追）
    │   └── 返回前 20 部
    │
    └── 相似推薦
        ├── 篩選用戶 ≥3 星電影
        ├── 計算相似度分數
        │   ├── 年代相近（±3年）
        │   ├── 評分相近（±1.5分）
        │   └── 人氣度相近
        ├── 排序並返回前 20 部
        └── 補充已看高分電影（若不足10部）
```

## 📝 數據模型

### Movie Object
```javascript
{
  id: number,              // TMDB ID
  title: string,           // 電影標題
  release_date: string,    // 發行日期
  year: string,           // 年份
  overview: string,        // 簡介
  poster_path: string,     // 海報路徑
  posterUrl: string,       // 完整 URL
  vote_average: number,    // TMDB 評分
  vote_count: number,      // 評分人數
  type: 'movie',          // 類型
  isWatched: boolean,      // 是否已看
  userRating: number,      // 用戶評分 (0-5)
  userReview: string,      // 用戶評論
  dateAdded: string,       // 添加日期
  dateWatched?: string     // 觀看日期
}
```
